03 · Apple Leaf Severity Tracker

Leaf and visible-damage segmentation, affected-area estimates, and a local observation history. Apple only; frame one identifiable leaf.

Real-image validation: area error averaged 3.01 percentage points on 80 held-out apple images, versus 4.37 for a zero-area baseline. Leaf Dice: 0.884; lesion Dice: 0.436. Fine lesion boundaries remain a limitation.

Start

Read README.md, install dependencies, and run leaf-severity demo --output outputs/my-demo. A fitted real-data head is included at artifacts/real_apple_model.npz; the first use downloads official pretrained ResNet18 weights.

Held-out real-image evaluation

One custom category-balanced grouped split: 160 training, 40 validation, and 80 test images. Thresholds were selected on validation only. No independent field-site or longitudinal validation is claimed.
